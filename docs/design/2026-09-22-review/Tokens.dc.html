1. Spacing scale, 8 px base

Every margin, padding and gap uses one of these six tokens. Nothing else.

--space-1
8 px: icon to label
--space-2
16 px: paragraph gap, gutter
--space-3
24 px: card padding, grid gap
--space-4
40 px: before an h2
--space-5
64 px: section to section
--space-6
96 px: hero band padding
